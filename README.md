# 🎬 GrabMyShow

GrabMyShow is a full-stack MERN movie ticket booking platform inspired by BookMyShow.

## 🚀 Tech Stack

- React
- Node.js
- Express
- MongoDB
- Socket.IO
- TMDB API

---

## Features

- Live movie data
- JWT Authentication
- Real-time seat booking
- Wishlist
- Reviews
- Admin Dashboard

---

Project is currently under development.
